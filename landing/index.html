Instant Dev Port Killer

Type :3000 to inspect listening sockets, identify zombie Node/Vite processes, and terminate them in 3.2ms without touching Task Manager.

🛡️

Capability Execution Broker

3-tier policy broker intercepts all system commands. Non-destructive operations run immediately, while writes, deletes, and shell executions require interactive dry-run approvals.

🔐

Windows DPAPI Secret Vault

Hardware-backed encryption via Windows Data Protection API (CryptProtectData). API keys and tokens are encrypted with your Windows account—never stored in plaintext.

Local Diagnostics & Safe Mode

Press Ctrl+Shift+D for an in-app privacy-safe diagnostics viewer. Broken or hanging extensions are auto-quarantined with --safe-mode recovery.

Frequently Asked Questions

Why does Windows SmartScreen show a blue warning?

Microsoft SmartScreen displays a warning for any executable that hasn't established automated cloud reputation via millions of downloads or an expensive Extended Validation (EV) certificate. AltSpace is 100% open-source; you can verify all code on GitHub and review reproducible GitHub Actions build logs. Simply click "More info" and "Run anyway".

Does AltSpace require an internet connection?

No! AltSpace is engineered local-first. App launching, file search, port termination, clipboard history, and local AI (via Ollama at localhost:11434) run completely offline without transmitting any telemetry or user data.

How does the 20% Contributor Treasury work?

For every supporter license or sponsor payment, 20% is set aside into a public treasury pool. Maintainers post wanted features and extension ideas as GitHub Issues with attached bounties. Community developers submit PRs, and once merged, bounties are paid directly via Polar.sh or GitHub Sponsors.
