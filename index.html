Multi-Drive Everything Indexer

Searches through hundreds of thousands of files across all partitions (C:, D:, network drives, and USB sticks) in sub-5ms using native C ABI Everything SDK. No background battery drain.

• Sub-5ms Indexing • Zero CPU at Idle • Folder Jump on Enter

Developer Port Killer

Inspect open localhost ports (:3000, :8080, :5432). Terminate stuck node or python processes with 1 click without Task Manager or `netstat`.

Type :ports or kill :3000

In-Memory Clipboard

Search your recent copies with auto-redaction for passwords, tokens, and private keys. Instant paste directly back into your editor.

Private Local Ollama AI

Connect to local Ollama (Llama 3, Mistral, Qwen) via Model Context Protocol. Summarize clipboard context without sending bytes to the cloud.

100% Offline & Private
