# AltSpace STRIDE Threat Model & Security Architecture

This document specifies the threat model, attack surfaces, security boundaries, and mitigations for AltSpace on Windows 10 and 11, evaluated against the **STRIDE** taxonomy (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege).

---

## 1. System Components & Trust Boundaries

```
[ Untrusted Web / User Input / Clipboard ]
                   │
                   ▼ (Boundary 1: Input Sanitization & Masking)
        ┌─────────────────────┐
        │   React / WebView2  │  <-- Non-Elevated UI (Untrusted)
        └──────────┬──────────┘
                   │
                   ▼ (Boundary 2: Typed Tauri IPC + Parameter-Bound Challenge Gate)
        ┌─────────────────────┐
        │  Native Rust Core   │  <-- Authoritative Boundary & Policy Gate
        │  & DPAPI Vault      │
        └────┬───────────┬────┘
             │           │
(Boundary 3) │           │ (Boundary 4)
             ▼           ▼
   ┌───────────────┐   ┌────────────────────────┐
   │ Contained     │   │ Windows OS & APIs      │
   │ Plugin Host   │   │ (Filesystem, Win32,    │
   │ (Blocked /    │   │  Everything64, SQLite, │
   │  Migration)   │   │  Process lpEnvironment)│
   └───────────────┘   └────────────────────────┘
```

### Trust Boundaries:
1. **Boundary 1 (Input/Renderer Boundary)**: Untrusted external strings (clipboard contents, search queries, external file paths, web responses) entering the WebView2 frontend.
2. **Boundary 2 (IPC & Broker Boundary)**: Communication between the frontend renderer and the authoritative native Rust backend via typed Tauri IPC, guarded by parameter-bound, single-use, 60-second expiring challenge tokens.
3. **Boundary 3 (Extension Confinement Boundary)**: Community script execution (`.ps1`, `.bat`, `.cmd`, `.py`, `.js`) is blocked with `BlockedForMigration` status. Existing manifests are preserved on disk without spawning unsandboxed processes.
4. **Boundary 4 (Host OS Boundary)**: File writes, process terminations, registry lookups, child process environment injection (`lpEnvironment`), and network calls.

## 2. STRIDE Threat Analysis & Mitigations

### S — Spoofing Identity

| Threat | Target | Risk | Mitigation in AltSpace |
| :--- | :--- | :--- | :--- |
| **Fake Entitlement Leases** | Licensing & Quota | High | Entitlement leases are cryptographically signed with HMAC-SHA256/Ed25519; client verifies signatures, expiration, and key IDs. Unverified leases default to Free. |
| **Impersonated IPC Messages** | IPC / Broker | High | Tauri commands for privileged operations require single-use, 60s-expiring challenge tokens generated by Rust and bound to the SHA-256 hash of the exact parameters. Replay attempts fail closed. |
| **Malicious Official Binary Impersonation** | Distribution & Update | Critical | Official releases are signed with Authenticode; `install.ps1` verifies Authenticode signatures with publisher validation and SHA-256 checksums before execution. Community forks must rebrand per `TRADEMARK.md`. |

### T — Tampering with Data

| Threat | Target | Risk | Mitigation in AltSpace |
| :--- | :--- | :--- | :--- |
| **Path Traversal Attacks** | Filesystem & Extensions | Critical | Script filenames and file paths are canonicalized; directory separators (`/`, `\`, `..`) are strictly rejected. Plugin install fails closed without modifying filesystem. |
| **UNC Path NTLM Exfiltration** | Search & Launch | High | Remote UNC paths (e.g., `\\attacker.com\share`) are detected and blocked from automatic indexing or preview execution. |
| **Shell Metacharacter Injection** | Shell Runner | High | Unbrokered shell command execution (`execute_shell_command`, `launch_in_terminal_window`, `RunPowerShell`) is permanently disabled and fails closed. |
| **Configuration Injection** | `.altconfig` Import | Medium | Configuration files are schema-validated; sensitive keys (tokens, entitlements, secrets) are stripped on export and rejected on import. |

### R — Repudiation

| Threat | Target | Risk | Mitigation in AltSpace |
| :--- | :--- | :--- | :--- |
| **Unattributable Native Actions** | Capability Broker | Medium | All native actions are logged to the in-memory ledger ring buffer with timestamps, target summaries, risk ratings, and outcomes. Credential values are automatically redacted. |
| **Unapproved AI Actions** | AI / MCP Intents | High | Destructive actions require user confirmation; history timeline displays approval timestamps and provides one-click undo for reversible operations. |

### I — Information Disclosure

| Threat | Target | Risk | Mitigation in AltSpace |
| :--- | :--- | :--- | :--- |
| **Plaintext Token Theft** | OAuth & API Keys | High | Sensitive credentials and session tokens are encrypted using Windows DPAPI (`CryptProtectData`) tied to the user's Windows login. Zero tokens in `localStorage`. Secrets never cross IPC. |
| **Clipboard Credential Leaks** | Clipboard History | High | In-memory regex scanner detects and masks private keys, bearer tokens, AWS secrets, and passwords before display; clipboard history is never written to disk. |
| **Telemetry Leaks in Diagnostics** | Logs & Diagnostics | Medium | Structured diagnostic exporter automatically redacts file paths, usernames, prompt strings, and tokens prior to display or export. |

### D — Denial of Service (DoS)

| Threat | Target | Risk | Mitigation in AltSpace |
| :--- | :--- | :--- | :--- |
| **Runaway Extension Processes** | Extension Runtime | High | Community script execution is completely blocked with `BlockedForMigration` status, eliminating runaway process and fork-bomb vulnerabilities. |
| **Repeated Crash Loops** | Startup & State | Medium | Safe Mode launch flag (`--safe-mode`) boots AltSpace with third-party extensions, custom themes, and cached state disabled. Auto-quarantine disables crashing extensions. |
| **Stale Search Overload** | Search Engine | Medium | Debounced search queries use `searchSeq` tokens and `AbortController` cancellation to drop stale in-flight results. |

### E — Elevation of Privilege

| Threat | Target | Risk | Mitigation in AltSpace |
| :--- | :--- | :--- | :--- |
| **Privilege Escalation via Extensions** | Child Processes | High | Community script execution is blocked. Plugins cannot spawn processes. |
| **Protected Process Killing** | Port Inspector (`:port`) | High | Protected system processes (PID 0, PID 4, csrss, lsass, services) and the AltSpace process itself are blacklisted from termination. |
| **Silent Execution of Dangerous Code** | AI & Terminal | High | Parameter-bound challenge policy: Level 2 and Level 3 actions always require cryptographically bound approval tokens. |

## 3. Residual Risks & Ongoing Controls

1. **Local Fork Modification**: Under Apache 2.0, local code can be modified. Mitigated by keeping commercial value (hosted AI, cloud sync, support, official releases) server-side behind cryptographic lease boundaries.
2. **Third-Party DLL Injection**: Running under standard Windows user session. Mitigated by Authenticode binary signing, verifying loaded DLL hashes, and strict path resolution.
