## 🤝 Where Does Your Money Go?

Every rupee or dollar contributed is managed transparently:
- **70% Core Engineering**: Directly supports full-time development, security audits, and Windows platform maintenance.
- **20% Contributor Bounty Treasury**: Automatically funds cash bounties for community developers who build useful extensions and fix bugs.
- **10% Infrastructure**: Pays for Windows Authenticode EV Code Signing certificates (removing Windows SmartScreen warnings) and build servers.

## 🔑 How to Activate Your Supporter License

1. Purchase a Supporter License online or via [Polar.sh](https://polar.sh) / [GitHub Sponsors](https://github.com/sponsors/codecheesee).
2. You will receive an offline-capable license key in the format:
   ```
   ALTSP-SUPPORTER-YYYYMMDD-HASH
   ```
3. Open AltSpace (<kbd>Alt</kbd> + <kbd>Space</kbd>).
4. Click **Menu** (<kbd>Ctrl</kbd> + <kbd>K</kbd>) or the **Supporter** link in the footer.
5. Paste your key and click **Activate**. Your Gold Supporter Badge will unlock immediately!

*(For testing and evaluation during development, you can use the dev test key: `ALTSP-SUPPORTER-2026`).*
